# Дорожная карта проекта

План развития eCommerce Starter Kit по этапам. Детали выполнения и текущий статус — в [PROGRESS.md](PROGRESS.md).

## Этап 1. Инфраструктура и базовое развертывание ✅ (завершен)

Docker Compose (PostgreSQL, Redis, Meilisearch, Medusa, Nuxt), единый `.env`, автоматическая инициализация (миграции, идемпотентный seed, администратор, publishable API key), демо-витрина с реальными товарами, базовая документация и API-справочник.

## Этап 2. Commerce API и базовый типизированный API-клиент ✅ (текущий, завершен)

- Типизированный API-клиент storefront на базе официального `@medusajs/js-sdk` (2.23.0): `useCommerce()` c группами `products`, `categories`, `collections`, `regions`.
- Composables: `useCommerce` (транспорт) и `useStore` (регионы, валюта, форматирование цен).
- Региональные рассчитанные цены, пагинация, таймаут, отмена запросов, единая нормализация ошибок `CommerceError`.
- Демо-страницы: главная, `/catalog` (пагинация), `/product/:handle` (404 для отсутствующего товара) — все на Commerce Client.
- Автотесты: unit (31) + интеграционные на живой Medusa (20), `make test`.
- `docs/api.md` (все используемые маршруты Store API), `docs/commerce-client.md`, `docs/composables.md`.

## Этап 3. Meilisearch, индексация, поиск и фасетная фильтрация

- Подключение Meilisearch к Medusa (штатный search-механизм или официальный плагин).
- Индексация товаров, синхронизация индекса с Medusa (subscribers/workflows).
- Поисковые API-маршруты, фасетная фильтрация, префикс индексов `MEILISEARCH_INDEX_PREFIX`.

## Этап 4. Frontend composables каталога, поиска и фильтров

- Composables: каталог, поиск, фильтры, пагинация.
- UI-примитивы витрины (Tailwind), примеры компонентов.

## Этап 5. Каталог и карточка товара

- Страница каталога (категории, сортировка, пагинация).
- Карточка товара: варианты, цены, изображения, наличие.
- SEO-мета для каталога (базовый уровень).

## Этап 6. Корзина, доставка, checkout и тестовая оплата

- Cart API, добавление/изменение позиций.
- Выбор способа доставки, checkout workflow, тестовый платежный провайдер (`pp_system_default`).
- Страницы корзины и оформления заказа.

## Этап 7. Авторизация, профиль и история заказов

- Auth API для клиентов (JWT/сессии), регистрация и вход.
- Личный кабинет: профиль, адреса, история заказов.

## Этап 8. SEO, информационные страницы и примеры layout

- sitemap, robots, canonical, Open Graph.
- Информационные страницы, примеры layout, документация по переиспользованию.

## Этап 9. Интеграции ЮKassa, Т-Банк и опциональная Strapi

- Платежные провайдеры ЮKassa и Т-Банк для Medusa (штатные плагины или собственные провайдеры по официальному гайду Medusa).
- Webhooks, возвраты.
- Опциональная интеграция со Strapi как CMS контентных страниц.

## Этап 10. Финальное тестирование и production-развертывание

- Production-сборка образов (`medusa build`, `nuxt build`), worker mode, reverse proxy, HTTPS.
- Нагрузочные/интеграционные проверки, чек-лист развертывания.
